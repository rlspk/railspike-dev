## Completion Contract
- Documentation-only writes: Markdown under `docs/research/historical_cycle_expansion/`, this feature's plans/folder, and its `docs/plans/README.md` entry. Catalog → evidence/dispositions → reconciled coverage → complete eligible-analysis queue; preserve sources and the original study. Freeze provenance/excerpts; append dated corrections. - Six stages, <=1 hour each. After approval: branch, organize/commit approved plans first; verify, summarize, and commit every stage before advancing. No application/tooling/generated-artifact changes. All candidates need dispositions; all canonical cycles need Step 2's metadata and evidence/unknown rationale.

## Key Risks
- **High risk: false counts/status.** Screening found 878 step documents, 256 provisional filename keys, installed duplicates, backlog work, corrected completion claims, and pending verification. Deduplicate using provenance/content, not names alone. Completion requires supporting records without known unmet gates; explicit outstanding mandatory gates qualify completion; affirmative unfinished work is in-progress; abandonment/supersession requires explicit evidence; otherwise indeterminate. Preserve later regressions separately.
- **High risk: drift.** Fingerprint sources and original study before review; record revisions/dirty state and retain classification excerpts. Rescan at handoff; record changes against the cutoff without overwriting sources or baseline.
- Capacity: 213 summary candidates total 12,488 lines. Four <=65-group batches cover the preliminary keys. Recheck broader discovery before dependent work; split oversized batches, returning to Step 2 if eight stages/a day cannot cover everything. Never silently sample.
