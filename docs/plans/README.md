# Feature plans

- [Plan organization](./fdp_feature_integration/fdp_feature_integration_step1_solution_assessment.md): first of two FDP integrations; debug mode is a separate follow-up.
- [Instruction debug mode](./instruction_debug_mode/instruction_debug_mode_step1_solution_assessment.md): second FDP integration, covering durable state, diagnostics, and logs.
- [Quiet debug mode](./quiet_debug_mode/quiet_debug_mode_step1_solution_assessment.md): file-first diagnostics with one-line conversational handoffs.
- [Website redesign](./website_redesign/website_redesign_step1_solution_assessment.md): redesigned landing page with the new logo, the Readings essay and voice selector, and a modernized QDB look.
- [Homepage from scratch](./homepage_from_scratch/homepage_from_scratch_step1_solution_assessment.md): new plain, text-first homepage with a real worked example and a limits section; the logo and paper are separate backlog features.
- [Essay homepage](./readme_and_essay_homepage/readme_and_essay_homepage_step1_solution_assessment.md): homepage becomes the maintainer's essay verbatim, simply formatted; the README stays as is.
- [Repository cleanup](./repo_cleanup/repo_cleanup_step1_solution_assessment.md): move maintainer files out of the root into `docs/maintainers/`, organize `docs/`, and document every remaining file in the README map.
- [Project debug default](./project_debug_default/project_debug_default_step1_solution_assessment.md): consuming-project marker file enables diagnostics by default for new workflows.
- [Whitepaper research](./railspike_paper/railspike_paper_step1_solution_assessment.md): exploratory debug evidence and feasibility assessment before comparative evaluation and publication.
- [Prompted installation](./prompted_installation/prompted_installation_step1_solution_assessment.md): agent-led installation, first-use welcome, and optional workflow reminders.
- [Installation process improvements](./installation_process_improvements/installation_process_improvements_step1_solution_assessment.md): reviewed copies by default, explicit submodules, recovery, and first-task planning.

- [Separate development content](./separate_development_content/separate_development_content_step1_solution_assessment.md): split the product into `rlspk/railspike` and development records/checks into `rlspk/railspike-dev`, with the website in `rlspk/rlspk.github.io`.
- [Historical cycle expansion](./historical_cycle_expansion/historical_cycle_expansion_step1_solution_assessment.md): census historical Railspike/FDP cycles before expanding outcome analysis.

- [Historical outcome analysis](./historical_outcome_analysis/historical_outcome_analysis_step1_solution_assessment.md)

- [Task-relevant instruction summaries](./remove_instruction_reprints/remove_instruction_reprints_step1_solution_assessment.md): replace automatic instruction reprints with brief summaries of the next action, constraints, and approval gate.

- [Enhancement requests and follow-up cycles](./mid_process_enhancements/mid_process_enhancements_step1_solution_assessment.md): durable request dispositions and distinct cycles on an unmerged shared branch.

- [First release](./first_release/first_release_step1_solution_assessment.md): verify and publish the initial signed v0.1.0 product release.

- [Railspike slides](./railspike_slides/railspike_slides_step1_solution_assessment.md): self-contained HTML slide deck explaining Railspike and how to use it; created in the website checkout, not yet linked or published.
- [Railspike slides polish](./railspike_slides_polish/railspike_slides_polish_step2_feature_description.md): follow-up cycle on the slide deck: opening promise, statement titles, a conclusion slide, sans-serif type, and a keynote voice; still unlinked and unpublished.

- [Debug log process improvements](./debug_log_process_improvements/debug_log_process_improvements_step1_solution_assessment.md): turn recurring debug feedback into bounded changes; first cycle makes a known user's recovery an acceptance condition and requires honest completion reporting.

- [Frozen reference recovery](./frozen_reference_recovery/frozen_reference_recovery_step2_feature_description.md): preserve exact R1 sources and repair portable host-ledger recovery.

- [Detailed effort estimates](./detailed_effort_estimates/detailed_effort_estimates_step1_solution_assessment.md): optional estimates for every solution option and planned stage, carried through execution revisions and retrospective assessments.

- [Extended estimates default](./extended_estimates_default/extended_estimates_default_step2_feature_description.md): default-on estimates for new enrolled cycles and v0.3.0-beta.2 publication.
