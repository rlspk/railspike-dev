# Railspike v0.3.0 beta 4

Step 3 plans written by one agent in one pass now use a single attribution footer for the whole plan, regardless of length.

- Use stage-level attribution only for stages subsequently authored or substantively revised separately.
- Preserve the original plan footer and prior attribution when recording revisions. Include model/settings only when verified.
- The generation template, review checklist and two-stage example now agree on this layout.

Extended estimates remain enabled by default for new enrolled cycles. Existing opt-outs, older cycle state, estimate semantics and approval/commit rules are unchanged.
