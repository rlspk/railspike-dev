# Railspike v0.7.0-beta.2

## Handoff prompts

Any cycle can now move to a new chat. Ask for a handoff prompt ("a prompt block" and "a prompt to continue in a new chat" also work). The agent commits the cycle's plans and pushes its feature branch. That request authorizes only this push: never to `main`, a PR or a merge. The agent then gives one code block naming the repository, branch, base commit, plan path, cycle, step, mode, and what is and is not approved. The new chat reads `AGENTS.md` and the plan, checks the branch against `origin/main`, and continues. The record wins over the prompt.

The approval commit gate now allows a separate commit labeled "draft, not approved" so a handoff can carry an unapproved plan. It never counts as the approval commit. `docs/failure-modes.md` covers a missing or stale branch, or a prompt that claims an approval the record lacks.

## Epic checklists

New `docs/workflow/epic_checklist.md` coordinates one outcome delivered in several one-shot and staged cycles. The checklist approves nothing; each item stays its own cycle. It opens with Resume here. An item's "(one-shot)" or "(staged)" mark is a lean, not authorization. Other rules cover stable IDs, layered status, nested follow-ups, an approver line, an MVP line, and keeping cut and superseded items. Estimates are never summed, and each epic cycle counts as its own effort-study outcome. A short template is included. Step 1 suggests an epic when an estimate goes above 1.0 and creates one only on request.

## Compatibility and upgrade

Backwards compatible. The only rule loosened is the labeled draft commit for handoffs; approval commits and branching are otherwise unchanged. This beta includes everything in v0.7.0-beta.1 (plan length guidance, debug log attribution) and stable v0.6.1.

Opt in through the README upgrade procedure, targeting `v0.7.0-beta.2` and preserving local changes. Existing installations do not update automatically. Roll back the same way to `v0.7.0-beta.1` or stable `v0.6.1`, preserving host records.

The beta is published from `feat/v0.7.0-beta.2`, which merges `feat/epic-checklists` into `feat/plan-length-and-agent-field`. Plan length guidance reached `main` on 2026-11-24 as a fast-forward to the v0.7.0-beta.1 commit (rlspk/railspike#2); handoff prompts and epic checklists wait in rlspk/railspike#1. Publishing this beta does not merge anything further into main. Stable Latest remains `v0.6.1`.
